# unofficial-template-univie-typst
Unofficial typst template for University of Vienna.

This repo was forked from [DDVLau/unofficial-template-univie-typst:main](https://github.com/DDVLau/unofficial-template-univie-typst) and is built based on [UniVie's official Overleaf template](https://www.overleaf.com/latex/templates/template-university-of-vienna/brhjgbvnzfmn). 

Additional styling changes have been made to make the typst template the original LaTeX template more closely. This Overleaf repo is under CC BY 4.0.
